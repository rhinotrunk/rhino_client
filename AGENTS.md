# RhinoClient

New C# files authored by an AI agent use a `.ai.cs` suffix. Existing files keep their names. Conventional generated and code-behind names (`*.Designer.cs`, `*.g.cs`, `*.xaml.cs`) are exempt.

Keep this starter small: C# owns Rhino integration, TypeScript owns the panel UI, and JSON messages connect them. Minimum supported host: Rhino 8.20 running .NET 8.
